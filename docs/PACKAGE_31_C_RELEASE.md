## R2 Standard

- 風險與費用控制採帳戶共用的 5 GB 操作管理目標。公益 Worker 的應用程式限制預設為 5,000,000,000 bytes，未來私密文件與其他產品如亦開通上傳，須把共同額度接至同一份計量或在各產品分配額度。
- `nxspace-public-media` 與 `nxspace-private-files` 都規劃為 Standard 私有桶，關閉公開開發網域和直接存取。公益 Worker 僅接公開素材桶的 `BRAND_MEDIA`。私密桶保留給日後需要身分、案件授權及 `no-store` 的文件功能。
- 0027 建立圖片登記。圖片以活動及隨機 ID 定位。後台接收 JPG、PNG 或 WebP，在瀏覽器轉成 WebP，Worker 驗證內容、尺寸、分流、每人每小時 30 件及個別檔案 2 MiB。公開路徑只讀取當前版本引用、且仍顯示的圖片。
- 每次更換以新 URL 避免舊快取延用，公開圖片的快取時間為五分鐘。移除會取消關聯，歷史版本所用物件保留供回滾。管理容量時先盤點未發布、已移除及歷史引用，由授權人員確認可清理範圍。
- 活動品牌發布限定於公益首頁的品牌資料，沿用既有草稿、預覽、版本與稽核。全站發布仍受 `DASHBOARD_WEBSITE_PUBLISH` 控制。
- 上線前先在隔離環境驗證 0027 和 R2，再依序作正式備份、套用增量遷移、設定公開桶綁定、部署候選及唯讀驗收。程式可回滾到上一個關閉版，新增表與物件可保留供重試。

## 用量與費用

- Cloudflare 的 Storage & databases → R2 → 選擇儲存桶 → Metrics，可查容量、讀寫操作與流量。[R2 Metrics and analytics](https://developers.cloudflare.com/r2/platform/metrics-analytics/)
- Cloudflare 的 Workers & Pages → 選擇 Worker → Metrics，可查請求及 CPU 用量；Manage Account → Billing → Billable Usage 可核對費用。[Cloudflare 帳戶計量](https://developers.cloudflare.com/billing/manage/billable-usage/)
- 計量付費帳戶可在 Billing → Billable Usage → Create budget alert 設定小額費用通知。也可檢查 Notifications 是否提供帳戶可用的用量通知。通知不等於停用額度。[Cloudflare Budget alerts](https://developers.cloudflare.com/billing/manage/budget-alerts/)
- Standard 每月包含 10 GB-month、100 萬次 Class A 和 1,000 萬次 Class B。超額單價與計費進位以官方價格為準。接近額度時先清查歷史素材、縮小檔案、確認快取效果，再評估後續用量。[R2 Pricing](https://developers.cloudflare.com/r2/pricing/)
