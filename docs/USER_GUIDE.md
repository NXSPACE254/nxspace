# User Guide

## Public site

Use the primary navigation to browse activities, vendors, products and venues. Lists support search, category, sorting and Load More. Rental and order confirmations remain in the same browser and can be found through Lookup with the record ID plus Email or phone last four digits.

## Venue rental

Choose a venue, date mode and time. Disabled dates and conflicts cannot be submitted. Complete contact, attendance and consent fields; save the generated `NXR` number.

## Dashboard

Open `/admin/`. First use creates a Local Demo Super Admin; later visits require that account. Navigation is permission-filtered. Editors validate records before save, confirm destructive actions and use status controls for publishing. Mobile navigation, dialogs and drawers support keyboard/Escape.

Users/Roles manage Demo identities and permissions. Integrations tests Local, public-read or protected-endpoint adapters. Settings handles safe backup/restore. Final Acceptance shows runtime checks and the protected Demo reset workflow.
# Beta V1.1 點餐

從「商店」或「線上點餐」選擇店家，設定取餐日期與時段後加入客製化餐點。購物車一次只能保留一家商店；送出後保存訂單編號，於「查詢」使用 Email 或手機末四碼查看進度。

店家可在管理中心快速開始／暫停接單、標記商品售完，並以優先卡片處理新訂單。通知中心顯示本機紀錄，不代表 LINE 已發送。
